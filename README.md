# University ERP System

A web-based University Enterprise Resource Planning (ERP) system designed to simplify academic and administrative operations through a centralized interface.

## Features

- **Dashboard:** Overview of key academic and administrative information.
- **Student Management:** Manage student records and information.
- **Staff Management:** Organize staff details and records.
- **Attendance Management:** Track and review attendance.
- **Fee Management:** Manage fee records, payments, and dues.
- **Reports:** View summaries and reports for administrative activities.
- **Academic Settings:** Configure relevant academic and institutional information.
- **Role-Based Interface:** Provide different views and navigation for different user roles.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser Local Storage and Session Storage

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/UKJxDev/Enterprise_Resource_Planning_University.git
   ```

2. Open the project folder.
3. Launch the main `index.html` file in your browser, or use a local development server if required by the project structure.

## Project Structure

The application is organized into HTML pages, stylesheets, and JavaScript modules for its various functional areas.

- **HTML:** Application pages and interface structure.
- **CSS:** Layout, styling, and responsive presentation.
- **JavaScript:** Application logic and module-specific functionality.
- **Browser Storage:** Local persistence of application data.

## Project Scope

This project demonstrates the implementation of common university and educational administration workflows in a browser-based application.

**Note:** This is a frontend project. Browser-based storage and client-side authentication, where implemented, are intended for demonstration purposes and should not be treated as production-grade security or centralized data management.
